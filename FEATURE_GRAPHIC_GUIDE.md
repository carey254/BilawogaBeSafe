# Feature Graphic Creation Guide

## What is a Feature Graphic?

The Feature Graphic is a **1024 x 500 pixel banner** that appears at the top of your app's Google Play Store listing page. It's the first visual element users see when they visit your app page.

## Requirements

- **Size:** Exactly 1024 pixels wide × 500 pixels tall
- **Format:** PNG or JPEG
- **Max file size:** 15 MB
- **Aspect ratio:** 2.048:1 (wide banner)

## Design Elements to Include

1. **App Name:** "BilaWoga" (large, prominent)
2. **Tagline:** "Your Personal Safety Companion" or "Emergency Safety App"
3. **Key Features:** "Stealth SOS • AI Detection • Auto Alerts"
4. **Visual Theme:** Safety/emergency colors (blue, red, or safety shield icon)

## How to Create Your Feature Graphic

### Option 1: Use the HTML Template (Easiest)

1. Open `feature-graphic.html` in a web browser
2. Take a screenshot or use a browser extension to capture the exact size
3. Use an image editor to ensure it's exactly 1024x500px
4. Save as PNG or JPEG

### Option 2: Use Online Design Tools

**Free Tools:**
- **Canva** (canva.com)
  - Search for "Google Play Feature Graphic" template
  - Size: 1024 x 500px
  - Customize with your text and colors

- **Figma** (figma.com)
  - Create new design: 1024 x 500px
  - Add text, colors, and icons

- **GIMP** (Free image editor)
  - Create new image: 1024 x 500px
  - Add text layers and design elements

### Option 3: Use Professional Design Software

- **Adobe Photoshop**
- **Adobe Illustrator**
- **Sketch**

## Design Tips

1. **Keep it Simple:** Don't overcrowd with too much text
2. **High Contrast:** Ensure text is readable
3. **Brand Colors:** Use your app's color scheme (blue for safety)
4. **Safety Theme:** Include safety-related icons (shield, SOS, location pin)
5. **Mobile-Friendly:** Remember it will be viewed on mobile devices

## Color Suggestions

- **Primary:** Blue (#1976D2) - Safety, trust
- **Accent:** Red (#F44336) - Emergency, alert
- **Background:** Dark blue gradient or white with blue accents
- **Text:** White or dark blue for contrast

## Text Hierarchy

1. **App Name:** Largest (60-80px)
2. **Tagline:** Medium (24-32px)
3. **Features:** Smaller (18-22px)

## Quick Steps to Create

1. **Choose your tool** (Canva recommended for beginners)
2. **Set canvas size:** 1024 x 500 pixels
3. **Add background:** Gradient or solid color
4. **Add app name:** "BilaWoga" (large, bold)
5. **Add tagline:** "Your Personal Safety Companion"
6. **Add features:** "Stealth SOS • AI Detection • Auto Alerts"
7. **Add icon/visual:** Safety shield or SOS icon (optional)
8. **Export:** PNG or JPEG format
9. **Verify:** Check it's exactly 1024x500px

## Upload to Play Console

1. Go to Play Console → Store listing
2. Scroll to "Feature graphic"
3. Click "Upload"
4. Select your 1024x500px image
5. Save
