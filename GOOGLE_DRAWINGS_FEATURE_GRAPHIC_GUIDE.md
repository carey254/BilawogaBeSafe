# How to Create Feature Graphic Using Google Drawings

## Step-by-Step Instructions

### Step 1: Open Google Drawings
1. Go to **https://docs.google.com/drawings**
2. Sign in with your Google account
3. Click **"Blank"** to create a new drawing

### Step 2: Set the Canvas Size
1. Click **File** → **Page setup**
2. Select **"Custom"**
3. Enter:
   - **Width:** 1024 pixels
   - **Height:** 500 pixels
4. Click **OK**

### Step 3: Add Background
1. Click **File** → **Page setup** → **Background**
2. Choose a color or gradient:
   - **Option 1:** Solid blue (#1976D2)
   - **Option 2:** Gradient (blue to darker blue)
3. Or use **Insert** → **Shape** → **Rectangle** to fill the entire canvas

### Step 4: Add App Name "BilaWoga"
1. Click **Insert** → **Text box**
2. Type: **BilaWoga**
3. Select the text
4. Format:
   - **Font:** Arial or Roboto (bold)
   - **Size:** 72-80pt
   - **Color:** White
   - **Alignment:** Center
5. Position it in the center-top area

### Step 5: Add Tagline
1. Click **Insert** → **Text box**
2. Type: **Your Personal Safety Companion**
3. Format:
   - **Font:** Arial (regular)
   - **Size:** 28-32pt
   - **Color:** White
4. Position it below the app name

### Step 6: Add Key Features
1. Click **Insert** → **Text box**
2. Type: **Stealth SOS • AI Detection • Auto Alerts**
3. Format:
   - **Font:** Arial (regular)
   - **Size:** 20-24pt
   - **Color:** White
4. Position it below the tagline

### Step 7: Add Safety Icon (Optional)
1. Click **Insert** → **Shape** → **Shapes** → **Shield** (if available)
2. Or use **Insert** → **Image** → **Search the web** → Search "safety shield icon"
3. Resize and position in top-right corner
4. Make it semi-transparent (Format → Transparency)

### Step 8: Center Everything
1. Select all elements (Ctrl+A or Cmd+A)
2. Use alignment tools:
   - **Arrange** → **Align** → **Center horizontally**
   - **Arrange** → **Align** → **Center vertically**

### Step 9: Export as Image
1. Click **File** → **Download**
2. Select **PNG image (.png)**
3. The file will download to your computer

### Step 10: Verify Size
1. Right-click the downloaded PNG file
2. Select **Properties** (Windows) or **Get Info** (Mac)
3. Check dimensions: Should be **1024 x 500 pixels**

## Quick Tips

- **Use grid:** View → Snap to → Grid (helps with alignment)
- **Group elements:** Select multiple items → Right-click → Group
- **Copy formatting:** Use Format Painter tool
- **Layers:** Right-click → Order to move elements forward/backward

## Alternative: Google Slides

If you prefer Google Slides:

1. Go to **https://docs.google.com/presentation**
2. Create new presentation
3. Click **File** → **Page setup** → **Custom**
4. Set: **1024 x 500 pixels**
5. Design your banner
6. **File** → **Download** → **PNG image (.png)**

**Note:** Slides will export the current slide only.

## Troubleshooting

**Problem:** Can't set exact pixel size
- **Solution:** Set in inches: 10.67" x 5.21" (1024/96 x 500/96)

**Problem:** Text looks blurry
- **Solution:** Use larger font sizes, avoid very small text

**Problem:** Export is wrong size
- **Solution:** After export, use an image editor to resize to exactly 1024x500

## Final Check Before Upload

✅ Image is 1024 x 500 pixels
✅ Format is PNG
✅ File size under 15 MB
✅ Text is readable
✅ Looks good on mobile preview
